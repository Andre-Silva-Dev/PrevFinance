# Plano de Desenvolvimento - PrevFinance

Este diretorio organiza o plano em fases independentes.
Cada fase possui um README com objetivo, escopo e criterio de conclusao, alem de tasks em arquivos separados.

## Fases

1. 01-Fundacao-e-Arquitetura
2. 02-Identidade-e-Multi-Tenancy
3. 03-Contas-Transacoes-e-Parcelamento
4. 04-Projecoes-e-Dashboard
5. 05-Quitacao-de-Dividas-e-Simulacoes
6. 06-Hardening-e-Release-MVP

## Como usar

1. Escolher uma fase para execucao.
2. Ler o README da fase.
3. Executar as tasks em ordem.
4. Registrar resultado no arquivo ContextoDesenvolvimento.md.
